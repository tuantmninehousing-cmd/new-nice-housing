7. DỰNG LẠI TỪ ĐẦU (khi mất máy chủ hoặc chuyển máy chủ)
======================================================================
1) Máy chủ Linux có Node 22, git, PostgreSQL, nginx, pm2.
2) git clone https://github.com/tuantmninehousing-cmd/new-nice-housing && cd new-nice-housing && git checkout nine-redesign
3) Tạo file .env theo README.md (kết nối PostgreSQL, JWT_SECRET – đặt chuỗi riêng, đừng để mặc định).
4) npm ci → npm run migrate (tạo bảng và dữ liệu mẫu) → npm run build → pm2 start npm --name ninehousing -- start
5) nginx trỏ tên miền ninehousing.com về cổng 3030, bật HTTPS.
6) Khôi phục (nếu còn bản sao): config/settings.json, public/uploads/, dữ liệu PostgreSQL (tòa nhà, đơn, bài viết).
7) Đăng nhập trang quản trị, làm lại mục 6.
8) Kiểm tra theo mục 8.
Nếu chỉ mất mã trên máy chủ: làm lại bước 2, 4 rồi chạy lệnh ở mục 3.
